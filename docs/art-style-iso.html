Revised

Feedback taken. The world keeps its fine tiles, but characters no longer shrink to match — that was making everything read the same and look zoomed-out. Dolls now render at a larger, higher-detail sprite (24×36): defined face, shaded torso with belt and trim, sleeves + hands, boots, and an outline + ground shadow. Detail is decoupled from tile resolution, so the hero keeps presence and reads as a character, not a map marker.

What this is. A verification re-render of the art-direction pivot. Every canvas runs the locked iso generators from iso-mockup-fine.html (the spec source) — geometry consts TW=16 · TH=8 · ZH=6, quantized 6-step lighting, and the revised detailed 24×36 character dolls. This is presentation only: the headless sim, saves, determinism, and paper-doll recipes are unchanged. Scenes are seeded, so the same seed yields the same world.
